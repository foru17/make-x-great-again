**入口与可靠性边界**

| 入口 / 调用方 | 身份和控制维度 | 失败与资源边界 |
|---|---|---|
| `/v1/classify`，插件页面 | 配置开启时要求 GitHub；身份或匿名 IP 的盐化指纹 | 缓存/规则命中免模型额度；模型路径每身份每小时 60 个逻辑预留，共享全局默认 2000；429/503 |
| `/v1/report`、`/v1/confirm` | GitHub/兼容匿名模式；举报去重、年龄与封禁检查 | 既有举报限流；需要模型时加入同一身份/全局预留；人工审核策略回归通过 |
| cron 分类补齐 | Worker 自身固定身份，非共享用户 IP | 每 tick 最多 3 批，每批 16 行；加入相同全局额度；拒绝时记录并退出 |
| `/v1/rule-hits` | 匿名 IP 盐化指纹 | 最多 50 条/批、12 批/小时；客户端队列最多 500，失败保留，15 秒请求截止 |
| 规则直接写入、申诉、白名单申请 | 规则写入身份/IP、申诉 IP、申请 GitHub | 既有每小时 30 / 5 / 10 次控制；旧计数辅助函数的不足见 R-01 |
| 管理员及 Agent API | 独立 bearer 身份，未开放公共 CORS | 未鉴权返回 403；实际 HTTP 与现有权限测试通过 |
| 名单/工件/健康与站点资源 | 公共读取；R2、资产与 D1 | 本地健康/站点入口验证；发布/镜像的生产性能未压测 |
| GitHub 身份校验 / Device Flow | 用户 token / GitHub 应用 | Worker userinfo 15 秒截止；真实授权与 GitHub 峰值额度未实测 |
| X 原生操作 | 用户主动设置的模式及现有 X 会话 | 执行前复查白名单/开关；测试只拦截请求，没有实际拉黑或静音真实账号 |
| 独立 agent runner / 离线 live eval | 项目外部执行环境及 provider 凭据 | 不共享 Worker 的 D1 额度；本轮只跑单元测试和 dry-run |

额度单位是保守的“逻辑尝试预留”，不是实际计费 token、金额或确认成功的调用数。每次最多两次模型解析尝试，失败不释放预留；默认 2000 最多对应 4000 次 provider 尝试。它不是 provider 账号级预算：独立 runner、评估及其他产品还可能共用该账号。超时后的计费状态未知，网络失败不自动重发，格式错误最多补问一次。

单页最多 40 次新检测及 10 次缓存复核，客户端同时执行上限 3；N 个页面最多形成 3N 个并发调用。cron 的结构上限为每小时 18 个逻辑批次、36 次 provider 尝试，并受共享额度约束。真实高峰分钟/全天流量、跨产品占用与预算余额没有证据，本报告不提出提高额度。生产拒绝事件有结构化日志；告警投递、值班归属与恢复通知尚未实测。
